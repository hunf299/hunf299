### 📂 My Projects

**Pipeline ETL**

- Tech stack: Python · Kafka · PySpark · MongoDB · MySQL
- Description: This project features an end-to-end Data Engineering pipeline that bridges batch processing and real-time streaming. It utilizes PySpark to clean and ingest raw JSON data into MongoDB, alongside a MySQL-to-Kafka CDC pipeline for real-time event streaming. Built with strict data validation, schema enforcement, and centralized configuration management.
- [View Details](https://github.com/hunf299/PipelineETL)

**AeroDelay**

- Tech stack: Python · Pandas/NumPy · Scikit-Learn/LightGBM · Selenium/BeautifulSoup4 · Streamlit · Dagster · Ollama
- Description: A data engineering and machine learning platform built to collect, preprocess, and analyze aviation and weather data for predicting flight delay propagation. The project implements a structured Medallion Architecture (Bronze → Silver → Gold layers) with automated pipeline orchestration. It features a complete pipeline from web scraping and time-series weather integration to advanced feature engineering, exploratory data analysis (EDA), and model training. Additionally, it includes a Streamlit interactive dashboard for data visualization, Dagster for workflow management, and a local LLM integration via Ollama for delay code annotation.
- [View Details](https://github.com/hunf299/DS108_AeroDelay)
- [View Demo](https://drive.google.com/drive/folders/1844w-krshQPnEcw12LdumviHB877955L?usp=share_link)

**Expanding limited software defect dataset**

- Tech stack: Python · PyTorch · Transformers (BERT/GTE) · LightGBM · Scikit-Learn · Streamlit
- Description: A machine learning platform developed to enhance bug report severity prediction by expanding software bug datasets (Eclipse, Mozilla, Netbeans, OpenOffice). The project maps out a 3-phase pipeline including Natural Language Processing(text normalization, text embedding), Feature Engineering (similarity features, pseudo-confidence checks, and historical priority scores), and dataset balancing via SMOTE. It establishes a baseline using a Hybrid CNN on the core dataset, then contrasts it against advanced models like Fusion Model(BERT+MLP), LightGBM, and Naive Bayes on the augmented dataset under a strict validation rule. The final model is served via an interactive web demo deployed on Streamlit.
- [View Details](https://github.com/hunf299/IE105_ExtendingSoftwareBugDatasets)
- [View Demo](https://softwarebug.streamlit.app)
